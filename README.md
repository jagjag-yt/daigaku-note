# 大学ノート(v0.2)

GoodNotes の代わりを目指す、無料・オフライン・クロスプラットフォームの手書きノート。
Web 技術(PWA)1本で Windows と iPad の両方で動く。ビルド不要、依存ライブラリは `vendor/` に同梱。
同じ画面を Capacitor で包んだ Android / iOS アプリ版もある(Android を先に進めている。くわしくは [docs/アプリ化.md](docs/アプリ化.md))。

## できること

- ペン(Apple Pencil / Windows のペンの筆圧に対応)。ペン先は万年筆・ボールペン・筆ペン・鉛筆から選べ、筆圧感度・手ぶれ補正・破線/点線も設定できる(ペンをもう一度押す)。線は滑らかなベクター(輪郭を塗ったパス)なので、拡大しても PDF にしても滑らか
- 蛍光ペン(下の文字が透けて見える)・マスキングテープ(暗記用。下の文字を隠し、押すとめくれる)。蛍光ペンをもう一度押して切り替え、直線で描く設定も
- 色:よく使う3色をツールバーに並べ、選んでいる色をもう一度押すと色のパネル(プリセットの編集・カスタムの色の表と HEX・スポイト・最近使った色)
- 図形補正(スマホ幅ではその他のメニュー):書き終わりでペンを止めると、直線・円・楕円・三角形・四角形に整える(「図形補正」でオン/オフ)
- 消しゴム:なぞった所だけ消す(普通・正確)か、線ごと消す(ストローク)を選べる。ペン・蛍光ペンのどちらを消すか絞り込める。消したら前の道具に戻す設定、ページを消去(元に戻せる)。ペンの消しゴムボタンにも対応
- テキスト:テキストの道具(T)で押した所に文字を打つ。文字を押すと書き直し。大きさ・書体(標準・明朝・等幅)・太字・斜体・下線・取り消し線・揃え・色・背景と枠を選べる
- 付箋:付箋の道具(N)で押した所に付箋を貼る(10色、日付入り)。押すと書き込める。文字の設定はテキストと同じ
- 画像:ツールバーの画像のボタンで写真・ファイル・カメラから入れる。貼り付け(Ctrl+V)・ドラッグでも入る。大きな写真は長い辺 2400px に縮めて保存
- 図形と矢印:ペンの設定の「図形を描く」で四角・楕円・三角・ひし形・直線・矢印・両矢印を選び、ドラッグした範囲に描く(ペンの色・太さ・線の種類で)
- 投げ縄:自由な形か長方形で囲んで選ぶ(ペン・蛍光ペン・画像・テキストのどれを選ぶか絞り込める)。ドラッグで移動、四隅のつまみで拡大縮小、下のつまみで回転。切り取り・コピー・貼り付け(別のノートにも)・複製・削除・色の変更
- 元に戻す / やり直す(Ctrl+Z / Ctrl+Y)
- テンプレート:A罫・B罫・C罫・B罫(余白線つき)・2段・方眼(5mm・10mm)・ドット・ToDo リスト・コーネル式・五線譜・無地。用紙は A4 縦横・B5・A5・16:9。紙の色は白・クリーム・黄・水色・薄緑・灰。新しいノートは前に選んだ用紙・サイズ・紙の色から始まる
- ページ一覧:並べ替え、テンプレートの変更、追加、削除。上のタブで「ページ / しおり / 目次」を切り替える
- しおりと目次:ページの操作(⌄)で、しおりを付ける・目次に見出しを付ける。その他のメニューから今のページにしおり
- ページを別のノートにコピー・移動(送り先の最後に入る。元に戻せる)
- ページの回転:ページの操作(⌄)の「右に回転」「左に回転」。PDF・罫線・手書きが一緒に回る(画像とテキストボックスは傾けず、位置だけ回る)
- ノート一覧(作成・名前変更・複製・1冊ずつ書き出し)。お気に入り(☆)、並べ替え(最終変更日・作成日・名前)、グリッドとリストの切り替え
- フォルダ:「新規」→「フォルダ」で作る。フォルダの中にフォルダも作れる。ノートやフォルダのメニューの「移動…」で入れ替え、上のパンくずで戻る。フォルダを削除すると、中のノートはゴミ箱へ(戻すといちばん上に出る)
- ゴミ箱:削除したノートはゴミ箱に入り、元に戻すか完全に削除できる(完全に削除したノートは本棚にも検索にも出ず、開けない。同期の記録の中身は残る)
- 端末内(IndexedDB)に自動保存。ネットなしで全部使える
- PDF を開いて上から書き込む / ノートに PDF のページを追加
- PDF 書き出し(元の PDF はそのまま残し、その上に手書きをベクターで重ねる)
- 検索:ノートの名前、PDF の文字
- クラウド同期(メールアドレスでログインするだけの大学ノートアカウント)と、ファイルでの同期
- GoodNotes のノート(.goodnotes)の取り込み(手書き・用紙・画像・テキストボックス・付箋)
- 指はスクロールとピンチズーム、書くのはペンだけ(「指で書く」で切り替え)
- ホーム画面に追加すればアプリとして起動、オフラインでも起動

ショートカット:P ペン / H 蛍光ペン / E 消しゴム / L 投げ縄 / T テキスト / N 付箋 / Delete 選択を削除 / Esc 選択解除 / Ctrl+C・X・V・D コピー・切り取り・貼り付け・複製

## 起動のしかた

### Windows

Node.js が入っていれば、`start-windows.bat` をダブルクリック(または `node serve.mjs`)。
ブラウザで http://localhost:8123/ が開く。Edge なら「アプリとしてインストール」でアプリになる。

### iPad

いちばん簡単なのは、このフォルダをどこか https で公開すること(GitHub Pages、Cloudflare Pages、Netlify など。
静的ファイルを置くだけ)。Safari で開いて「共有 → ホーム画面に追加」。

試すだけなら、Windows で `node serve.mjs` を動かし、同じ Wi-Fi の iPad から表示された
`http://192.168.x.x:8123/` を開く。ただし https でないのでオフライン起動はできない。

### Android(アプリ版)

[docs/アプリ化.md](docs/アプリ化.md) を参照。Android Studio のエミュレーターで動かす手順と、
Android Studio なしで APK を入れる方法(GitHub Actions が作る)を書いてある。

## 同期のしかた

### 大学ノートアカウント(ログインが必要)

大学ノートを使うには、ログインが必要。ログインしていないときは、本棚やノートの代わりにログインのページが出る。

- **はじめての人**:「アカウントを作成」のページ(`#/signup`)でメールアドレスを入れて「確認番号を送る」。メールに届いた6桁の番号を入れるとアカウントができ、本棚が開く
- **アカウントがある人**:「ログイン」のページ(`#/login`)でメールアドレスを入れて「ログイン番号を送る」。届いた番号を入れるとログインする
- ログインのページでアカウントのないアドレスを入れたときは、番号を確かめたあとに「このアドレスでアカウントを作成」が出る(同じ番号のまま作れる)。
  アカウント作成のページですでにあるアドレスを入れたときは、そのままログインする
- 番号を送ったあとにメールのアプリへ行って戻ってきても、番号の入力から続けられる。パスワードはない

ログインしたあと:

- ログインの状態は端末の中に覚えるので、オフラインでも読み込み直してもログインしたまま使える
- 変更の約20秒後(書いている途中は待つ)、ノートを閉じたとき・アプリを離れたとき、1分ごとに自動で同期する
- 1人 1GB まで(変更 + PDF・画像)。超えると「容量の上限(1GB)に達しました」と出て、この端末の変更は端末に残ったまま送られない
- 本棚の右上の人のボタン(頭文字)で、使っている容量・ログイン中の端末・ログアウト・アカウントの削除
- ログインできる端末は5台まで。アカウントの画面の「ログイン中の端末」で、なくした端末などを外せる。外された端末はログインのページに戻る
- 「ログアウト」「アカウントを削除」をすると、ログインのページに戻る。どちらも端末の中のノートは消えず、この端末で書いた内容は次にログインしたアカウントに同期される
  (前と別のアカウントでログインするときは、番号を送る前に確かめる画面が出る。そこで「この端末のノートを消して続ける」を選ぶと、
  もう一度確かめてから、この端末のノート・PDF・画像・設定をすべて消して読み込み直す。共有の端末で、前の人のノートを混ぜずに使い始めるため)
- 以前の版の「自分のサーバーを使う(WebDAV / Nextcloud)」の設定欄はなくした。WebDAV で同期していた端末も、ログインすると大学ノートアカウントでの同期に切り替わる(大学ノートアカウントに送るのは、それぞれの端末で書いた内容。ほかの端末で書いた内容は、その端末でもログインすると届く)
- サーバーは `server/`(Cloudflare Workers)。アプリから見ると WebDAV のフォルダ(`daigaku-note/ops/<端末ID>/*.json` と `daigaku-note/files/*`)で、同期の仕組みは `js/webdav.js`
- 各端末は「ほかの端末の変更を何番まで読んだか」だけを覚えて、その続きだけを読む。変わっていない端末のフォルダは中を見ない
  (フォルダの ETag で判断。くわしくは `docs/設計.md`)

### ファイルで同期

1. 端末Aの一覧で「同期」→「同期ファイルを書き出す」
2. そのファイルを OneDrive / Google ドライブ / AirDrop などで端末Bへ
3. 端末Bで「同期」→「同期ファイルを取り込む」

どちらの方法でも、何回取り込んでも、どの順で取り込んでも同じ結果になる。

## GoodNotes からの取り込み

一覧の「GoodNotesから取り込む」で `.goodnotes` を選ぶ(複数可)。
GoodNotes の形式は公開されていないため、実物を調べて分かった範囲で読んでいる。

- 取り込めるもの:ノートの名前、ページの順番と大きさ、手書きの線(色・太さ・筆圧による太さの変化)、半透明の線(蛍光ペンとして)、鉛筆(筆圧つきのペンとして)、
  図形、消した線の除外、背景の PDF、画像、テキストボックス、付箋
- 取り込めないもの:鉛筆などの質感、画像の回転・切り抜き、リンク、音声

## 検索

一覧の検索欄で、ノートの名前と PDF のページの文字を探せる。手書き文字の認識は今は行わない
(将来、手書きを認識して文字入力や数式に変換する機能を作るときに、手書き向けの方法で入れる予定)。

## しくみ

- ノートは「変更(op)の記録」の積み重ね。op には `{端末ID, 端末内の連番, ランポート時計}` が付く。
- 状態は op をどの順で適用しても同じになるように作ってある(線・ページの「ある/消えた」、名前、ページ順をそれぞれ LWW で決める)。
  だから同期は「相手が持っていない op を送る」だけ。GoodNotes の .goodnotes の中身(端末ごとの時計付きイベント記録)と同じ考え方。
- PDF は SHA-256 で名前を付けて丸ごと1つ保存し、ページは「どの PDF の何ページ目か」を参照するだけ。
- 主なファイル
  - `js/model.js` データモデルとマージ(DOM なし、Node でテスト可)
  - `js/ink.js` 線の形(滑らかな中心線・筆圧の輪郭)、図形補正、投げ縄の判定
  - `js/templates.js` テンプレートと用紙サイズ
  - `js/search.js` 検索
  - `js/webdav.js` クラウド同期
  - `js/account.js` 大学ノートアカウント(同期サーバーへのログイン)
  - `js/goodnotes.js` .goodnotes の取り込み
  - `js/db.js` IndexedDB
  - `js/pdf.js` PDF の読み込み(pdf.js)と書き出し(pdf-lib)
  - `js/sync.js` 同期ファイル
  - `js/app.js` 画面と入力
  - `sw.js` オフライン用 Service Worker
- 設計の考え方と GoodNotes の調査からの反映: `docs/設計.md`
- メールのログインだけで同期できる同期サーバー(Cloudflare Workers): `server/`(手順は `server/README.md`)

### 同期ファイルの形式(v1)

```json
{
  "format": "daigaku-note-sync", "version": 1, "device": "端末ID", "exportedAt": "ISO時刻",
  "ops": [{ "id": "端末ID:連番", "d": "端末ID", "c": 1, "l": 1, "n": "ノートID", "t": "stroke.add", "p": {}, "ts": 0 }],
  "files": [{ "hash": "sha256", "name": "a.pdf", "type": "application/pdf", "data": "data:...base64" }]
}
```

op の種類: `note.create / note.rename / note.delete / note.restore / page.add / page.delete / page.restore / page.move / page.bg / stroke.add / stroke.del / stroke.undel / stroke.tf(移動) / stroke.style(色)`。
線の点は `[x, y, 筆圧, x, y, 筆圧, ...]`(単位は pt、ページ左上が原点)。

## テスト

```
npm test                            # マージ・図形補正・同期のカーソル・GoodNotes の線の読み方・アプリ版の通信・同期サーバーのテスト(Node)
npm ci && npm run test:ui           # 画面の崩れ(8つの画面の大きさ × Chromium・WebKit。docs/アプリ化.md)と、ログイン・アカウント作成の画面のテスト
node serve.mjs 8124 &               # アプリ
node test/worker-server.mjs 8131 &  # テスト用の同期サーバー(番号はメールで送らず応答に入れる)
node test/native-e2e.cjs            # アプリ版(Android)の動きをブラウザで再現して確かめる
npm i pdf-lib && URL=http://localhost:8124/ GN=見本.goodnotes node test/e2e.cjs /tmp   # ブラウザでの通し確認(Playwright)
```

## まだないもの(次の候補)

- 画像・テキストの貼り付け(取り込んだものの表示・移動はできる)
- 手書き文字の認識(文字入力・数式への変換)
- フォルダ分け(設計は `docs/設計.md`)、ページのサムネイル一覧からのドラッグでの並べ替え
- Google ドライブ・OneDrive への直接の同期
